# คู่มือเชื่อมแอป AI กับ Sub360

สั่งงาน Sub360 จากแชตของ Claude, ChatGPT, Gemini, Claude Code หรือ Codex ได้ เช่น "ใส่ซับไทยให้คลิป D:\clips\รีวิว.mp4 สไตล์คาราโอเกะ แก้คำว่ามิสทีนให้ถูก แล้วเรนเดอร์" งานจะเกิดใน Sub360 บนเครื่องคุณ เห็นความคืบหน้าในหน้าต่าง Sub360 เหมือนกดเอง และแอป AI ส่งลิงก์ดูคลิปกลับมาให้

ทุกอย่างอยู่ที่ **ตั้งค่า → แท็บเชื่อมแอป AI** (หรือเมนู **เชื่อมแอป AI** ในแถบข้าง)

## ก่อนเริ่ม

- **ปิดไว้เป็นค่าเริ่มต้น** เปิดสวิตช์ด้านบนการ์ดเมื่อต้องการใช้ ปิดเมื่อไหร่ ไม่มีแอป AI ใดทำอะไรได้ และทางเข้าจากอินเทอร์เน็ตหยุดทันที
- **AI ทำไม่ได้โดยตั้งใจ:** ลบโปรเจกต์, ติดตั้งเครื่องมือ (FFmpeg, whisper, cloudflared), ใส่หรือลบ Gemini API key, อัปเดตโปรแกรม, เปิดหรือปิดการเชื่อมต่อเอง
- **AI ต้องถามคุณในแชตก่อน:** งานที่ส่งข้อมูลไป Google Gemini (AI แก้คำ ส่งเสียงของคลิป · แปลซับ ส่งข้อความซับ) และงานที่ทับซับเดิม (ถอดเสียงใหม่, นำเข้าไฟล์ซับทับ, แบ่งท่อนใหม่) Sub360 บังคับเอง ไม่ได้พึ่งให้ AI จำ
- **ดูได้อย่างเดียว:** ติ๊กในการ์ดแล้วแอป AI อ่านได้อย่างเดียว หยุดการสร้าง แก้ และเรนเดอร์ชั่วคราว
- **สิ่งที่แอป AI ทำล่าสุด** อยู่ท้ายการ์ด ดูได้ว่าแอปไหนทำอะไรเมื่อไร
- ข้อความซับที่ AI อ่านคือเสียงพูดในวิดีโอของคุณ ข้อความนั้นจะถูกส่งให้ผู้ให้บริการ AI ที่คุณใช้
- ถ้า AI แก้ซับระหว่างที่คุณเปิดหน้าโปรเจกต์นั้นอยู่ หน้าต่างจะโหลดฉบับล่าสุดให้เอง (ยกเว้นตอนคุณกำลังพิมพ์แก้อยู่ ของคุณจะถูกบันทึกทับ)

## วิธีที่ 1 · แอป AI ในเครื่องนี้ (แนะนำ)

ใช้ได้กับ Claude Desktop, Claude Code, Codex, Gemini CLI, Cursor · วิดีโอไม่ออกจากเครื่อง ไม่ต้องมีบัญชีหรือโทเค็น

1. แท็บ **เชื่อมแอป AI** → เปิดสวิตช์ → หัวข้อ **แอปบนคอมพิวเตอร์เครื่องนี้** → เลือกแอปที่ใช้
2. ทำตามขั้นตอนในการ์ด แล้วกด **คัดลอก** ไปวาง

| แอป | วางที่ไหน |
|---|---|
| Claude Desktop | Settings → Developer → Edit Config → ไฟล์ `claude_desktop_config.json` (ถ้ามี `mcpServers` อยู่แล้ว เพิ่มเฉพาะส่วน `"sub360"`) แล้วปิด Claude ให้สนิทและเปิดใหม่ |
| Claude Code | รันคำสั่งที่คัดลอกในเทอร์มินัลครั้งเดียว |
| Codex | ท้ายไฟล์ `~/.codex/config.toml` |
| Gemini CLI | `~/.gemini/settings.json` ส่วน `mcpServers` |
| แอปอื่น (Cursor ฯลฯ) | ไฟล์ตั้งค่า MCP ของแอปนั้น (รูปแบบ `mcpServers` เดียวกัน) |

3. ไม่ต้องเปิด Sub360 ค้างไว้ก็ได้ สั่งงานครั้งแรกแล้ว Sub360 จะเปิดขึ้นมาเอง

ค่าที่คัดลอกชี้ไปที่ `Sub360.exe` ในเครื่อง (ทำงานแทน Node ได้ ไม่ต้องติดตั้งอะไรเพิ่ม) ติดตั้ง Sub360 ใหม่ในที่อื่นเมื่อไร ให้คัดลอกใหม่

## วิธีที่ 2 · แอป AI บนคลาวด์ (ChatGPT, Claude บนเว็บ, Gemini)

แอปพวกนี้ทำงานบนเซิร์ฟเวอร์ของผู้ให้บริการ จึงต้องเปิด **ทางเข้าจากอินเทอร์เน็ต** มาที่เครื่องนี้ก่อน ผ่านทางนี้เข้าได้แค่ส่วน MCP (หน้าแอปและไฟล์อื่นเข้าไม่ได้) มี 2 แบบ:

| แบบ | เหมาะกับ | ที่อยู่ |
|---|---|---|
| **เปิดทางเข้าด้วย Cloudflare** | ลองใช้ ใช้นาน ๆ ครั้ง | สุ่มใหม่ทุกครั้งที่เปิด และปิดเองเมื่อปิด Sub360 เปิด Sub360 ใหม่ต้องกดปุ่มอีกครั้งและเพิ่มการเชื่อมต่อในแอป AI ใหม่ |
| **ใช้ URL ของฉัน** | ใช้ประจำ | ที่อยู่ของ tunnel ของคุณเอง ไม่เปลี่ยน เพิ่มในแอป AI ครั้งเดียวใช้ได้ตลอด |

**ปุ่ม Cloudflare**

1. กด **เปิดทางเข้าด้วย Cloudflare** (ครั้งแรกจะดาวน์โหลด cloudflared ของ Cloudflare ราว 55 MB และตรวจลายนิ้วมือไฟล์ก่อนใช้)
2. คัดลอก **ที่อยู่สำหรับวางในแอป AI** (ลงท้ายด้วย `/mcp`)

**ใช้ URL ของฉัน (ที่อยู่คงที่)**

1. Cloudflare Zero Trust → Networks → Tunnels → สร้าง tunnel → รันคำสั่งติดตั้งที่ Cloudflare ให้ (`cloudflared service install …`) บนเครื่องนี้ใน PowerShell แบบผู้ดูแลระบบ
2. เพิ่ม Public Hostname (เช่น `sub360.example.com`) ให้ชี้ไปที่ `http://localhost:4370` — พอร์ต **4370** คือ gateway ของ Sub360 (ไม่ใช่หน้าแอป ถ้าชี้ผิดพอร์ต Sub360 จะปฏิเสธและบอกพอร์ตที่ถูก)
3. ใน Sub360 กด **ใช้ URL ของฉัน** วาง `https://sub360.example.com` แล้วกด **ใช้ที่อยู่นี้**

**เพิ่มในแอป AI**

| แอป | ขั้นตอน |
|---|---|
| ChatGPT | Settings → Apps & Connectors → Advanced → เปิด Developer mode → Create → วางที่อยู่ เลือก OAuth ไม่ต้องกรอก Client ID |
| Claude บนเว็บ/มือถือ | Settings → Connectors → Add custom connector → วางที่อยู่ → Connect |
| Gemini | เมนูเชื่อม MCP server / Connected apps → วางที่อยู่ |

แอป AI จะเปิดหน้า **เชื่อมต่อแอป AI กับ Sub360** ในเบราว์เซอร์ และ Sub360 จะแจ้งรหัส 6 หลัก (แจ้งเตือน Windows แถบด้านบนของหน้าต่าง และในแท็บเชื่อมแอป AI) พิมพ์รหัสนั้นในหน้าเบราว์เซอร์แล้วกด **เชื่อมต่อ** การเชื่อมจะขึ้นในหัวข้อ **แอปที่เชื่อมผ่านอินเทอร์เน็ต** กด **ยกเลิก** ได้ทุกเมื่อ มีผลทันที

**ข้อควรระวัง**

- รหัสใช้ได้ครั้งเดียว ภายใน 10 นาที และอยู่แค่ในหน้าต่าง Sub360 บนเครื่องคุณ คนที่รู้ที่อยู่ทางเข้าแล้วเปิดหน้าขอเชื่อมเองจะเชื่อมไม่ได้ ถ้าไม่มีใครบอกรหัสให้
- ถ้ารหัสขึ้นมาทั้งที่คุณไม่ได้กำลังเชื่อมแอปไหน ไม่ต้องทำอะไร อย่าบอกรหัสกับใคร และอย่าพิมพ์รหัสในเว็บที่คนอื่นส่งมาให้
- พิมพ์รหัสผิด 10 ครั้ง รหัสถูกปิดและหยุดแจ้งรหัสเอง 10 นาที ถ้าคุณกำลังเชื่อมเอง กด **รับรหัสเชื่อมแอปใหม่** ได้ทันที
- **ที่อยู่ทางเข้าเปลี่ยน:** เปิด Sub360 ใหม่ (ปุ่ม Cloudflare) หรือเปลี่ยน URL ของฉัน Sub360 ยกเลิกการเชื่อมที่ผูกกับที่อยู่เดิมให้เอง และขึ้นแถบบอกว่าแอปไหนถูกยกเลิก ให้ลบตัวเชื่อม Sub360 เดิมในแอป AI แล้วเพิ่มใหม่ด้วยที่อยู่ปัจจุบัน (Sub360 เข้าไปลบในบัญชี ChatGPT/Claude/Gemini ของคุณไม่ได้)
- แอปบนคลาวด์**นำเข้าวิดีโอจากเครื่องเองไม่ได้** ให้ลากวิดีโอเข้าหน้าต่าง Sub360 ก่อน (เลือก "ไม่ต้องถอดเสียง" ได้) แล้วค่อยสั่งงานต่อจากแชต

## ลิงก์ดูคลิป

เรนเดอร์เสร็จแล้ว แอป AI ส่ง **ลิงก์หน้าดูคลิป** ให้: เล่นวิดีโอได้ เลื่อนได้ และมีปุ่มดาวน์โหลด MP4

- เปิดทางเข้าจากอินเทอร์เน็ตอยู่ → เปิดจากมือถือหรือเบราว์เซอร์ไหนก็ได้ · ยังไม่ได้เปิด → ได้ลิงก์ที่เปิดบนเครื่องนี้ และแอป AI จะบอกให้เปิดทางเข้าก่อน
- ลิงก์ใช้ได้ **7 วัน** และเปิดได้เฉพาะตอนคอมพิวเตอร์เครื่องนี้และ Sub360 เปิดอยู่ (ไฟล์ส่งจากเครื่องคุณโดยตรง ไม่อัปโหลดไปที่ไหน)
- **ใครได้ลิงก์ไปก็ดูวิดีโอนั้นได้** จนหมดอายุ ยกเลิกทุกลิงก์ได้ที่หัวข้อ **ลิงก์ดูคลิป** ในการ์ด
- ปุ่ม Cloudflare ได้ที่อยู่ใหม่เมื่อเปิดใหม่ ลิงก์เก่าที่ผ่านอินเทอร์เน็ตจะใช้ไม่ได้ ขอลิงก์ใหม่จากแอป AI ได้เลย

## แก้ปัญหา

| อาการ | ทางแก้ |
|---|---|
| แอป AI บอก "การเชื่อมต่อ AI ของ Sub360 ปิดอยู่" | ตั้งค่า → เชื่อมแอป AI → เปิดสวิตช์ |
| แอป AI บอก "ดูข้อมูลได้อย่างเดียว" | เอาติ๊ก **ให้แอป AI ดูข้อมูลได้อย่างเดียว** ออก |
| แอป AI บอก "Sub360 ยังไม่ได้เปิด" | เปิด Sub360 เองแล้วสั่งใหม่ (ถ้าเปิดเองไม่ขึ้น ดู log ใน `%LOCALAPPDATA%\Sub360\logs`) |
| Claude Desktop ไม่เห็น tools ของ Sub360 | ตรวจว่าวาง JSON ถูกที่และเป็น JSON ที่ถูกต้อง แล้วปิด Claude ให้สนิท (รวมไอคอนที่ถาด) แล้วเปิดใหม่ |
| ย้ายที่ติดตั้ง Sub360 แล้วใช้ไม่ได้ | คัดลอก config จากแท็บเชื่อมแอป AI ใหม่ |
| ChatGPT/Claude/Gemini เชื่อมไม่ได้หลังเปิด Sub360 ใหม่ | ที่อยู่ปุ่ม Cloudflare เปลี่ยนแล้ว: กดเปิดทางเข้าอีกครั้ง ลบตัวเชื่อมเดิมในแอป AI แล้วเพิ่มใหม่ — หรือใช้ URL ของฉันเพื่อไม่ต้องทำแบบนี้อีก |
| ใช้ URL ของฉันแล้วแอป AI เข้าไม่ได้ | ตรวจว่า tunnel ทำงานอยู่ และ Public Hostname ชี้ไปที่ `http://localhost:4370` (ไม่ใช่พอร์ตหน้าแอป) |
| พอร์ต 4370 ถูกใช้อยู่ | ปิดโปรแกรมที่ใช้พอร์ตนั้น หรือตั้ง `SUB360_MCP_GATEWAY_PORT` ใน `.env` ให้ตรงกับที่ tunnel ชี้มา |
| หน้าเชื่อมต่อบอก "ยังไม่ได้เริ่มเชื่อมแอปใหม่ใน Sub360" | รหัสหมดอายุ (10 นาที) หรือถูกหยุดชั่วคราวเพราะพิมพ์ผิดหลายครั้ง: กด **รับรหัสเชื่อมแอปใหม่** ในการ์ด |
| ลิงก์ดูคลิปเปิดไม่ได้ | หมดอายุ (7 วัน) ถูกยกเลิก ที่อยู่ทางเข้าเปลี่ยน หรือคอมพิวเตอร์/Sub360 ปิดอยู่: ขอลิงก์ใหม่จากแอป AI |
| AI บอกต้องใส่ Gemini API key | ใส่เองที่ ตั้งค่า → AI แก้คำและแปล (AI ใส่แทนไม่ได้) |
