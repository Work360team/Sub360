# คู่มือเชื่อมแอป AI กับ Sub360

สั่งงาน Sub360 จากแชตของ Claude, ChatGPT, Gemini, Claude Code หรือ Codex ได้ เช่น "ใส่ซับไทยให้คลิป D:\clips\รีวิว.mp4 สไตล์คาราโอเกะ แก้คำว่ามิสทีนให้ถูก แล้วเรนเดอร์" งานจะเกิดใน Sub360 บนเครื่องคุณ และเห็นความคืบหน้าในหน้าต่าง Sub360 เหมือนกดเอง

ทุกอย่างตั้งที่เมนู **เชื่อมต่อ AI** ในแอป Sub360

## ก่อนเริ่ม

- **AI ทำไม่ได้โดยตั้งใจ:** ลบโปรเจกต์, ติดตั้งเครื่องมือ (FFmpeg, whisper, cloudflared), ใส่หรือลบ Gemini API key, อัปเดตโปรแกรม, อนุมัติการเชื่อมต่อของตัวเอง
- **AI ต้องถามคุณในแชตก่อน:** งานที่ส่งข้อมูลไป Google Gemini (AI แก้คำ ส่งเสียงของคลิป · แปลซับ ส่งข้อความซับ) และงานที่ทับซับเดิม (ถอดเสียงใหม่, นำเข้าไฟล์ซับทับ, แบ่งท่อนใหม่) Sub360 บังคับเอง ไม่ได้พึ่งให้ AI จำ
- ข้อความซับที่ AI อ่านคือเสียงพูดในวิดีโอของคุณ ข้อความนั้นจะถูกส่งให้ผู้ให้บริการ AI ที่คุณใช้
- ถ้า AI แก้ซับระหว่างที่คุณเปิดหน้าโปรเจกต์นั้นอยู่ หน้าต่างจะโหลดฉบับล่าสุดให้เอง (ยกเว้นตอนคุณกำลังพิมพ์แก้อยู่ ของคุณจะถูกบันทึกทับ)

## วิธีที่ 1 · แอป AI ในเครื่องนี้ (แนะนำ)

ใช้ได้กับ Claude Desktop, Claude Code, Codex, Gemini CLI, Cursor · วิดีโอไม่ออกจากเครื่อง ไม่ต้องมีบัญชีหรือโทเค็น

1. เปิด Sub360 → เมนู **เชื่อมต่อ AI** → กล่อง **แอป AI ในเครื่องนี้** → เลือกแอปที่ใช้
2. กด **คัดลอก** แล้ววางตามที่หน้าแอปบอก

| แอป | วางที่ไหน |
|---|---|
| Claude Desktop | Settings → Developer → Edit Config → ไฟล์ `claude_desktop_config.json` (ถ้ามี `mcpServers` อยู่แล้ว เพิ่มเฉพาะส่วน `"sub360"`) แล้วปิดเปิด Claude ใหม่ |
| Claude Code | รันคำสั่งที่คัดลอกในเทอร์มินัลครั้งเดียว |
| Codex | ท้ายไฟล์ `~/.codex/config.toml` |
| Gemini CLI | `~/.gemini/settings.json` ส่วน `mcpServers` |
| Cursor / อื่น ๆ | ไฟล์ตั้งค่า MCP ของแอปนั้น (รูปแบบ `mcpServers` เดียวกัน) |

3. ไม่ต้องเปิด Sub360 ค้างไว้ก็ได้ สั่งงานครั้งแรกแล้ว Sub360 จะเปิดขึ้นมาเอง

ค่าที่คัดลอกชี้ไปที่ `Sub360.exe` ในเครื่อง (ทำงานแทน Node ได้ ไม่ต้องติดตั้งอะไรเพิ่ม) ติดตั้ง Sub360 ใหม่ในที่อื่นเมื่อไร ให้คัดลอกใหม่

## วิธีที่ 2 · แอป AI บนคลาวด์ (ChatGPT, Gemini, claude.ai)

แอปพวกนี้ทำงานบนเซิร์ฟเวอร์ของผู้ให้บริการ จึงต้องมีที่อยู่ https ให้เรียกเข้ามา Sub360 ใช้ **Cloudflare Tunnel** ที่เปิดเฉพาะช่องสั่งงาน AI (ไม่เปิดหน้าแอป ไม่เปิดไฟล์) และทุกแอปต้องได้รับอนุญาตจากหน้าต่าง Sub360 ก่อน

1. เมนู **เชื่อมต่อ AI** → ติ๊ก **เปิดให้แอป AI บนคลาวด์เชื่อมต่อ**
2. ถ้ายังไม่มี cloudflared กด **ติดตั้ง** (ดาวน์โหลดจาก GitHub ของ Cloudflare ~60 MB)
3. เลือกแบบที่อยู่
   - **ชั่วคราว** ไม่ต้องมีบัญชี แต่ที่อยู่เปลี่ยนทุกครั้งที่เปิด Sub360 ใหม่ ต้องเพิ่มการเชื่อมต่อในแอป AI ใหม่ทุกครั้ง เหมาะกับการลองใช้
   - **ถาวร** ใช้โดเมนของคุณที่อยู่บน Cloudflare: Cloudflare Zero Trust → Networks → Tunnels → สร้าง tunnel → เพิ่ม Public Hostname (เช่น `sub360.example.com`) ให้ชี้ไปที่ `http://localhost:4370` → คัดลอกคำสั่งติดตั้งที่มีโทเค็น `eyJ…` มาวางในช่อง **โทเค็น tunnel** พร้อมชื่อโดเมน แล้วกด **บันทึกและเชื่อมต่อ**
4. เมื่อขึ้น **เชื่อมต่อแล้ว** กด **คัดลอก** ที่อยู่ (ลงท้ายด้วย `/mcp`) แล้วเพิ่มในแอป AI:

| แอป | ขั้นตอน |
|---|---|
| ChatGPT | Settings → Apps & Connectors → Advanced → เปิด Developer mode → Create → วางที่อยู่ เลือก OAuth ไม่ต้องกรอก Client ID |
| Claude (claude.ai / แอป) | Settings → Connectors → Add custom connector → วางที่อยู่ → Connect |
| Gemini | เมนูเชื่อมแอป / MCP server ของ Gemini → วางที่อยู่ |

5. แอป AI จะเปิดหน้า **เชื่อมต่อแอป AI กับ Sub360** ในเบราว์เซอร์ และหน้าต่าง Sub360 จะเด้งขึ้นมาที่หน้าเชื่อมต่อ AI พร้อมรหัส 6 หลักและชื่อแอปที่ขอ (ใช้ได้ครั้งเดียว ภายใน 10 นาที) ถ้าหน้าต่างไม่ขึ้น กด **เชื่อมแอป AI ใหม่** ใน Sub360 เอง
6. พิมพ์รหัสนั้นในหน้าเบราว์เซอร์แล้วกด **เชื่อมต่อ** ระบบจะพากลับไปที่แอป AI เอง
7. การเชื่อมทั้งหมดอยู่ในหัวข้อ **แอปที่เชื่อมไว้** กด **ยกเลิก** ได้ทุกเมื่อ มีผลทันที

**ข้อควรระวัง**

- รหัสใช้เชื่อมได้ครั้งเดียว และอยู่แค่ในหน้าต่าง Sub360 บนเครื่องคุณ คนที่รู้ที่อยู่ tunnel แล้วเปิดหน้าขอเชื่อมต่อเองจะเชื่อมไม่ได้ ถ้าไม่มีใครบอกรหัสให้ · ถ้ารหัสเด้งขึ้นมาทั้งที่คุณไม่ได้กำลังเชื่อมแอปไหน หรือขึ้นชื่อแอปที่ไม่รู้จัก ให้กด **ยกเลิก**
- อย่าบอกรหัสกับใคร และอย่าพิมพ์รหัสในเว็บที่คนอื่นส่งมาให้ ใช้เฉพาะหน้าที่แอป AI ของคุณเปิดขึ้นมา ถ้าหน้านั้นเตือนว่า **ปลายทางไม่ใช่แอป AI ที่ Sub360 รู้จัก** ให้กดยกเลิก
- พิมพ์รหัสผิด 10 ครั้ง ระบบจะปิดรหัสนั้นและหยุดเด้งรหัสเอง 10 นาที ถ้าคุณกำลังเชื่อมเอง กด **เชื่อมแอป AI ใหม่** เพื่อรับรหัสใหม่ได้ทันที
- แอปที่เชื่อมแล้วสั่งงาน Sub360 บนเครื่องนี้ได้ ยกเว้นข้อห้ามด้านบน แอปบนคลาวด์**นำเข้าวิดีโอจากเครื่องเองไม่ได้** ให้ลากวิดีโอเข้าหน้าต่าง Sub360 ก่อน (เลือก "ไม่ต้องถอดเสียง" ได้) แล้วค่อยสั่งงานต่อจากแชต

**ผลลัพธ์เป็นลิงก์ออนไลน์**

เมื่อเปิดแอป AI บนคลาวด์ไว้ เรนเดอร์เสร็จแล้วแอป AI จะได้ **ลิงก์วิดีโอ MP4** (และไฟล์ซับ) ผ่าน Cloudflare ไว้ดูหรือดาวน์โหลดจากที่ไหนก็ได้ ทั้งแอปบนคลาวด์และแอปในเครื่อง

- ลิงก์ใช้ได้ **3 วัน** และเปิดได้เฉพาะตอนคอมพิวเตอร์เครื่องนี้ Sub360 และ tunnel เปิดอยู่ (ไฟล์อยู่บนเครื่องคุณ ไม่ได้อัปโหลดไปที่ไหน)
- **ใครมีลิงก์ก็เปิดได้** อย่าแชร์ลิงก์ของวิดีโอที่ยังไม่อยากเผยแพร่
- ยกเลิกลิงก์ที่เคยให้ไปทั้งหมดได้ที่หน้า **เชื่อมต่อ AI** → **ยกเลิกลิงก์ที่เคยให้ไปทั้งหมด**
- ที่อยู่ชั่วคราว (Quick Tunnel) เปลี่ยนทุกครั้งที่เปิด Sub360 ใหม่ ลิงก์เก่าจะใช้ไม่ได้ ถ้าต้องการลิงก์ที่อยู่ได้นาน ใช้ที่อยู่ถาวร
- ปิดสวิตช์เมื่อไม่ใช้ tunnel จะหยุดทันที · ปิดโปรแกรม Sub360 tunnel ก็หยุดเช่นกัน
- ตัวอย่างการเชื่อมผ่านคลาวด์ยังไม่ได้ทดสอบกับ ChatGPT/Gemini/claude.ai ตัวจริง (ทดสอบ OAuth ครบวงจรผ่าน Quick Tunnel แล้ว) ถ้าเจอปัญหาแจ้งทีมพัฒนาพร้อมชื่อแอป

## แก้ปัญหา

| อาการ | ทางแก้ |
|---|---|
| แอป AI บอก "Sub360 ยังไม่ได้เปิด" | เปิด Sub360 เองแล้วสั่งใหม่ (ถ้าเปิดเองไม่ขึ้น ดู log ใน `%LOCALAPPDATA%\Sub360\logs`) |
| Claude Desktop ไม่เห็น tools ของ Sub360 | ตรวจว่าวาง JSON ถูกที่และเป็น JSON ที่ถูกต้อง แล้วปิด Claude ให้สนิท (รวมไอคอนที่ถาด) แล้วเปิดใหม่ |
| ย้ายที่ติดตั้ง Sub360 แล้วใช้ไม่ได้ | คัดลอก config จากหน้าเชื่อมต่อ AI ใหม่ |
| tunnel ขึ้น "มีปัญหา" | กด **ลองใหม่** · โหมดถาวร: ตรวจว่า Public Hostname ชี้ไป `http://localhost:4370` และโทเค็นถูกต้อง |
| พอร์ต 4370 ถูกใช้อยู่ | ปิดโปรแกรมที่ใช้พอร์ตนั้น หรือตั้ง `SUB360_MCP_GATEWAY_PORT` ใน `.env` ให้ตรงกับที่ตั้งใน Cloudflare |
| ที่อยู่ชั่วคราวใช้ไม่ได้แล้ว | เปิด Sub360 ใหม่แล้วที่อยู่เปลี่ยน: ลบการเชื่อมต่อเก่าในแอป AI แล้วเพิ่มด้วยที่อยู่ใหม่ |
| หน้าเชื่อมต่อบอก "ยังไม่ได้เริ่มเชื่อมแอปใหม่ใน Sub360" | รหัสหมดอายุ (10 นาที) หรือถูกหยุดชั่วคราวเพราะพิมพ์ผิดหลายครั้ง: กด **เชื่อมแอป AI ใหม่** ใน Sub360 แล้วพิมพ์รหัสที่ขึ้นมา |
| ลิงก์วิดีโอเปิดไม่ได้ | ลิงก์ใช้ได้ 3 วัน และเฉพาะตอนคอมพิวเตอร์ Sub360 และ tunnel เปิดอยู่ · ที่อยู่ชั่วคราวเปลี่ยนเมื่อเปิด Sub360 ใหม่ ลิงก์เก่าจึงใช้ไม่ได้: ขอลิงก์ใหม่จากแอป AI (ให้เรียก get_project) |
| แอป AI บนคลาวด์บอกนำเข้าไฟล์ไม่ได้ | ตั้งใจไว้แบบนั้น: ลากวิดีโอเข้าหน้าต่าง Sub360 เอง แล้วให้ AI หาโปรเจกต์ |
| การเชื่อมหายไปเอง | ถ้ามีการใช้โทเค็นเก่าซ้ำ (สัญญาณว่ามีคนอื่นถือสำเนา) Sub360 จะยกเลิกการเชื่อมนั้นเพื่อความปลอดภัย ให้เชื่อมใหม่ |
| AI บอกต้องใส่ Gemini API key | ใส่เองที่ ตั้งค่า → Gemini API key (AI ใส่แทนไม่ได้) |
