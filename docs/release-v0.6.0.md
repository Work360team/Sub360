# Sub360 v0.6.0

**หน้าตั้งค่าใหม่ แบ่งเป็นแท็บ และการเชื่อมแอป AI ย้ายมาอยู่ในนั้น** ใช้หลักเดียวกับ Clip360: เปิดปิดได้ในที่เดียว มีแถบบอกว่าเครื่องพร้อมหรือยัง และที่อยู่ทางเข้าที่ใช้ไม่ได้แล้วถูกล้างให้เอง

## สิ่งที่เปลี่ยน

### หน้าตั้งค่า

- **แบ่งเป็น 4 แท็บ:** เครื่องมือ · AI แก้คำและแปล · เชื่อมแอป AI · อัปเดตและไฟล์ แถบแท็บติดอยู่ด้านบนตอนเลื่อนลง และใช้ลูกศรซ้ายขวาบนคีย์บอร์ดสลับแท็บได้
- **แถบสรุปความพร้อม:** ด้านบนบอกในแถวเดียวว่าถอดเสียง เรนเดอร์ AI แก้คำ และแอป AI พร้อมหรือยัง เรื่องที่ยังไม่พร้อมกดแล้วพาไปแท็บที่แก้ได้เลย
- เมนู **เชื่อมแอป AI** ในแถบข้างพาไปแท็บนี้ ลิงก์เดิม (#/connect) ก็ยังพามาถูกที่
- บนจอมือถือ แถบแท็บเลื่อนซ้ายขวาได้

### การเชื่อมต่อ AI (MCP)

- **ปิดไว้เป็นค่าเริ่มต้น** มีสวิตช์เดียวด้านบนการ์ด ปิดเมื่อไหร่ ไม่มีแอป AI ใดทำอะไรกับ Sub360 ได้ และทางเข้าจากอินเทอร์เน็ตหยุดทันที (ถ้าเคยใช้หน้าเชื่อมต่อ AI ใน v0.5.x สวิตช์จะเปิดไว้ให้เหมือนเดิม)
- **ทางเข้าจากอินเทอร์เน็ตเหลือ 2 แบบ:** ปุ่ม **เปิดทางเข้าด้วย Cloudflare** ไม่ต้องสมัครอะไร กับ **ใช้ URL ของฉัน** สำหรับคนที่มี tunnel ของตัวเองที่ที่อยู่ไม่เปลี่ยน (เช่น Cloudflare Tunnel ที่ผูกโดเมน ติดตั้งเป็น service บนเครื่อง) — เลิกโหมดวางโทเค็น tunnel ในแอป ถ้าเคยตั้งไว้ แอปเปลี่ยนเป็น "ใช้ URL ของฉัน" ด้วยโดเมนเดิมให้
- **ล้างการเชื่อมที่ใช้ไม่ได้แล้ว:** เปิดแอปใหม่หรือที่อยู่ทางเข้าเปลี่ยน Sub360 ยกเลิกการเชื่อมที่ผูกกับที่อยู่เดิมให้เอง และขึ้นแถบบอกว่าแอปไหนถูกยกเลิก ต้องลบตัวเชื่อมในแอป AI แล้วเพิ่มใหม่ (Sub360 เข้าไปลบในบัญชี ChatGPT/Claude/Gemini ของคุณไม่ได้) การเชื่อมผ่าน URL ของฉันไม่ถูกแตะ
- ปุ่ม Cloudflare ไม่เปิดเองตอนเปิดแอปแล้ว เพราะที่อยู่เปลี่ยนทุกครั้งอยู่ดี
- **แจ้งเตือน Windows แทนการสลับหน้า:** เมื่อแอป AI ขอเชื่อม หน้าต่าง Sub360 ไม่กระโดดไปหน้าอื่นอีกแล้ว (งานที่ทำค้างไม่หาย) แจ้งเตือนของ Windows และแถบบนหน้าแอปบอกรหัส 6 หลักให้พิมพ์
- **ลิงก์ดูคลิป:** แอป AI ส่งลิงก์หน้าดูวิดีโอ (เล่นได้ เลื่อนได้ มีปุ่มดาวน์โหลด MP4) ให้แทนลิงก์ไฟล์ ลิงก์ใช้ได้ 7 วัน ยังไม่ได้เปิดทางเข้าก็ได้ลิงก์ที่เปิดบนเครื่องนี้ ยกเลิกทุกลิงก์ได้ในแท็บเชื่อมแอป AI
- **ดูได้อย่างเดียว:** ติ๊กแล้วแอป AI อ่านได้อย่างเดียว หยุดการสร้าง แก้ และเรนเดอร์ชั่วคราว
- **สิ่งที่แอป AI ทำล่าสุด:** แสดง 5 รายการล่าสุด กดดูทั้งหมดได้ (เก็บ 50 รายการ)
- **cloudflared ตรึงรุ่นและลายนิ้วมือไฟล์ (SHA-256):** ไฟล์ที่ดาวน์โหลดมาไม่ตรงกับที่ Cloudflare เผยแพร่จะไม่ถูกเปิดเลย
- **กันเปิดทั้งแอปออกเน็ต:** ถ้า tunnel ของคุณเองชี้มาผิดพอร์ต (หน้าแอปแทน gateway) Sub360 ปฏิเสธทุกคำขอที่มาทาง tunnel และบอกพอร์ตที่ถูก

## วิธีใช้งาน

1. ติดตั้ง **Sub360-Setup.exe** รุ่น 0.6.0 หรือรอให้แอปที่ติดตั้งไว้แล้วอัปเดตเอง
2. เปิด **ตั้งค่า** ดูแถบสรุปด้านบนก่อน ถ้ามีเรื่องที่ยังไม่พร้อม กดเรื่องนั้นเพื่อไปแก้
3. จะสั่งงานจากแชต: แท็บ **เชื่อมแอป AI** → เปิดสวิตช์ → เลือกแอปในเครื่องแล้วคัดลอกค่าไปวาง หรือกด **เปิดทางเข้าด้วย Cloudflare** สำหรับ ChatGPT, Claude บนเว็บ และ Gemini
4. ถ้าเคยเพิ่ม Sub360 ในแอป AI ด้วยที่อยู่ trycloudflare.com ให้ลบตัวเชื่อมนั้นแล้วเพิ่มใหม่ด้วยที่อยู่ปัจจุบัน

## การตรวจสอบและข้อจำกัด

ทดสอบด้วยชุดทดสอบอัตโนมัติ 51 ข้อ รวมการย้ายข้อมูลจาก v0.5.x การยกเลิกการเชื่อมเมื่อที่อยู่เปลี่ยน tunnel ที่เปลี่ยน Host และหน้าดูคลิป ทดสอบผ่าน Cloudflare Quick Tunnel จริง (เปิดจากปุ่มในแท็บใหม่ → จับคู่ด้วยรหัส → ขอลิงก์ดูคลิปของโปรเจกต์จริง → เปิดหน้าดูและเลื่อนวิดีโอผ่าน Cloudflare) และเปิดทุกแท็บบนจอคอมและจอมือถือ

- ยังไม่ได้ทดสอบแจ้งเตือน Windows ในแอปที่ติดตั้งจริง และยังไม่ได้ทดสอบกับ ChatGPT, Claude บนเว็บ, Gemini, Claude Desktop ตัวจริง
- "ใช้ URL ของฉัน" ยังไม่ได้ทดสอบกับ Cloudflare Tunnel ที่ผูกโดเมนจริง (ทดสอบด้วยการจำลอง)
- ทางเข้าจากอินเทอร์เน็ตและลิงก์ดูคลิปใช้ได้เฉพาะตอนที่คอมพิวเตอร์เปิด Sub360 อยู่

Windows x64 · ตัวติดตั้งยังไม่ได้ลงลายเซ็น Authenticode
